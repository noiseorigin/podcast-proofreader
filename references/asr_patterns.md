# 中文播客 ASR 常见错听模式与纠错策略

本文件总结了中文播客 ASR（自动语音识别）转写中常见的错误模式，供校对流程参考。

## 一、高频错听类型

### 1.1 专有名词错听

ASR 倾向于将不常见的专有名词（人名、地名、品种名）替换为发音相近的常见词。

| 错听类型 | 示例 | 纠错策略 |
|---------|------|---------|
| 节目名 | 猪多多花园 → 朱兜兜花园 | 根据节目名固定替换 |
| 主播名 | 玉子 → 芋子；猪兜兜 → 朱兜兜 | 根据开场自我介绍识别 |
| 嘉宾名 | ASR 通常正确，但社交平台名可能乱码 | 参考嘉宾自我介绍 |
| 植物名 | 积水分离 → 积水凤梨；快递海棠 → 块根秋海棠 | 需领域术语表 |
| 地名 | 喜马拉雅雅山 → 喜马拉雅山 | 去除重复字 |
| 学名 | bigod a rex → Begonia rex | 需确认后替换 |

### 1.2 同音/近音词混淆

| 错听 | 正确 | 语境提示 |
|------|------|---------|
| 袁总 | 原种 | 讨论植物品种时 |
| 电机种 | 奠基种 | 讨论育种基础时 |
| 地灾 | 地栽 | 讨论种植方式时 |
| 旋律 | 选育 | 讨论育种过程时 |
| 御龙家 | 育种家 | 讨论职业身份时 |
| 蜂花性 | 丰花性 | 讨论植物开花特性时 |
| 高速度 | 高湿度 | 讨论环境参数时 |
| 回蓝天 | 回南天 | 讨论天气现象时（两广地区） |
| 贵妃猪 | 龟背竹 | 讨论植物种类时 |
| 热值/热滞 | 热植 | 讨论植物类别时 |
| 花猪 | 花烛 | 讨论植物种类时 |
| 塘泥/糖泥 | 塘泥 | 讨论土壤时（糖泥为错听） |
| 麻叶秋海棠 | 蟆叶秋海棠 | "麻叶"为旧称/错听，"蟆叶"为正确（Rex begonia） |
| 白纸叶/白石砚 | 白芷叶 | 秋海棠品种名 |
| 快跟/快根 | 块根 | 讨论植物根类型时 |
| 球经/球技 | 球茎 | 讨论植物茎类型时 |

### 1.3 动词混淆

| 错听 | 正确 | 语境提示 |
|------|------|---------|
| 交水 | 浇水 | 讨论浇水动作时 |
| 交的是热水 | 浇的是热水 | 同上 |
| 痒（植物） | 养 | "痒到现在" → "养到现在" |
| 氧化 | 养护 | "氧化的方式" → "养护的方式" |

### 1.4 结构性错误

| 错听 | 正确 | 说明 |
|------|------|------|
| 大鹏 | 大棚 | "鹏"→"棚"（温室） |
| 巨屋 | 巨物 | "巨物开花"为固定说法 |
| 软调 | 软掉 | 植物死亡描述 |
| 重英 | 重影 | 叶片花纹描述 |
| 拿来主意 | 拿来主义 | 固定词组 |
| 夜叉/夜查/夜场 | 叶插 | 植物繁殖方式 |

### 1.5 复合错听（整句乱码）

ASR 有时会将一整段话听成完全不相干的内容。这类错误无法通过简单替换修复，需要人工回听。

**识别特征：**
- 句子语法不通但每个词都是合法中文
- 上下文断裂，前后文不衔接
- 出现与主题完全无关的词汇

**处理策略：**
- 在疑点清单中标注 `[⚠️?]`
- 保留原文，不猜测替换
- 标注时间戳供人工定位

## 二、发言人识别策略

### 2.1 自动识别

扫描前 5 分钟的文本，寻找自我介绍模式：

- "大家好，我是XXX" → 主播1
- "我是XXX" → 主播2 或嘉宾
- "嗨大家好，我叫XXX" → 嘉宾

### 2.2 发言人编号映射

通义听悟等 ASR 工具通常输出 `发言人1`、`发言人2`、`发言人3`：
- 发言人1 通常是第一个说话的人（可能是嘉宾或主播）
- 需根据开场白内容确定身份
- 嘉宾通常在开场后被介绍

### 2.3 多人对话区分

- 3人以上对话时，ASR 可能混淆发言人编号
- 建议人工确认前 10 分钟的发言人映射
- 后续内容基于确认结果批量替换

## 三、BGM 歌词处理

ASR 会将背景音乐歌词也转写成文本。处理策略：

1. **识别**：歌词通常出现在非对话语境中，内容与主题无关
2. **标注**：在歌词段落前后添加 `<!-- BGM -->` 标记
3. **不删除**：保留原文，由人工决定是否移除
4. **疑点清单**：在疑点清单中标注"BGM段落"，列出时间戳范围

## 四、保育相关内容处理

当 ASR 文本涉及以下内容时，必须保守处理：

- 野生植物采集/盗采描述
- 保护等级（国家一级/二级保护植物）
- 濒危物种状况
- 法规相关内容

**规则：**
- 不增强、不改写、不 embellish 事实
- 保留原文表述
- 在疑点清单中标注"保育"类别
- 由人工确认表述准确性

## 五、术语累积机制

每期校对完成后，将确认的术语写入 `glossary/epXXX_confirmed_terms.md`：

```markdown
# epXXX 已确认术语

来源：用户人工确认，YYYY-MM-DD。

## 植物与园艺名词
- 术语1
- 术语2

## 人名/称呼
- 人名1

## 常见错听映射
- 错听词 -> 正确词
```

后续期数校对时，自动加载已有术语表，实现跨期累积。

# 已确认术语

本目录保存创作者人工确认过的术语。每期一个文件，例如 `ep042_confirmed_terms.md`。

## 推荐格式

```markdown
# ep042 已确认术语

来源：创作者人工确认，YYYY-MM-DD。

## 人名与称呼
- 嘉宾姓名（发言人1）
- 主播姓名（发言人2）

## 品牌与专有名词
- OpenAI
- ChatGPT

## 已确认错听映射
- Open AI -> OpenAI
```

## 使用原则

1. 只记录已经由创作者确认的内容。
2. 后续节目可以把旧术语作为参考，但仍需结合语境判断。
3. 只有能够无歧义直接替换的映射，才合并到项目根目录的 `corrections.json`。

# Glossary — 已确认术语

本目录存放每期校对后人工确认的术语，跨期累积使用。

## 文件组织

- `README.md` — 本文件（格式说明）
- `epXXX_confirmed_terms.md` — 每期确认的术语（一个文件对应一期）

## 术语文件格式

```markdown
# epXXX 已确认术语

来源：用户人工确认，YYYY-MM-DD。

## 人名/称呼
- 主播A（发言人2）
- 主播B（发言人3）
- 嘉宾名（发言人1）

## 领域术语
- 术语1
- 术语2

## 已确认错听映射
- 错听词1 -> 正确词1
- 错听词2 -> 正确词2

## 保育相关（保守处理）
- 术语X（不增强、不改写）
```

## 使用方式

1. 每期校对完成后，将人工确认的术语写入 `epXXX_confirmed_terms.md`
2. 后续期数校对时，AI agent 会自动加载已有术语表
3. 跨期累积的错听映射可合并到项目根目录的 `corrections.json` 中
